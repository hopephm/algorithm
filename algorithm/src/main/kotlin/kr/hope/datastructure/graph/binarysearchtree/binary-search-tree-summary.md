# 🧭 이진 검색 트리 요약

---

## 📘 개념

**이진 검색 트리(binary search tree)** 는  
효율적인 자료 검색, 삽입, 삭제 연산을 수행하기 위한 자료구조로
노드 왼쪽에는 작은 값을 갖는 노드가, 오른쪽에는 큰 값을 갖는 노드가 자식이 되도록 구성된 이진 트리이다.

---

## ⚙️ 절차

| 단계       | 설명                                                                              |
|----------|---------------------------------------------------------------------------------|
| ① 삽입     | 루트 노드부터 작은 값인 경우 왼쪽 노드, 큰 값인 경우 오른쪽 노드로 이동하며 노드가 비어있는 곳에 삽입                     |
| ② 검색     | 루트 노드부터 작은 값인 경우 왼쪽 노드, 큰 값인 경우 오른쪽 노드로 이동하며 값 비교, 중위 순회시 정렬된 데이터               |
| ③ 삭제     | 삭제 노드의 왼쪽 노드를 삭제된 노드 자리로 옮기고, 옮겨진 노드의 오른쪽 자식(혹은 왼쪽 자식)을 오른쪽 노드의 가장 왼쪽 자식 위치로 이동 |

---

## ⚙️ 특징

- 삽입, 검색, 삭제 연산은 트리의 높이 h에 비례: O(h)
- 값 삽입 순서에 따라 전체 노드 수 N이 h가 될 수 있음: O(N)
- 트리의 높이를 평탄화 하는 작업이 중요 (balanced binary search tree): O(logN)
    - 종류: red-black tree, avl tree, treap 등
