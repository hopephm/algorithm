# Red-Black Tree (레드-블랙 트리) 요약

---

## 📘 개념

**레드-블랙 트리(Red-Black Tree)**는 **자기 균형 이진 탐색 트리**의 실무 표준입니다.  
5가지 색상 규칙으로 트리 높이를 최대 **2×log₂(n+1)** 이하로 유지해 **모든 연산을 O(log n)** 으로 보장합니다.

### ⚙️ 핵심 규칙

| 번호 | 내용                                | 위반 시 발생 문제           |
|----|-----------------------------------|-----------------------------|
| 1  | 모든 노드는 Red 또는 Black               | -                           |
| 2  | 루트는 항상 Black                      | 루트가 Red면 즉시 수정       |
| 3  | 모든 NIL(리프)은 Black                 | 블랙 높이 기준              |
| 4  | Red 노드의 자식은 절대 Red가 될 수 없다        | → Red-Red 충돌 발생 시 Fix-up |
| 5  | 모든 단순 경로(루트→NIL)는 동일한 수의 Black 노드 | 트리 균형 보장               |
| 6  | 새 노드는 항상 Red로 삽입                  | 트리 균형 보장               |

## ⚙️ 삽입 후 Fix-up : Uncle 색상에 따른 두 가지 전략

| Uncle 색상 | 전략            | 동작 내용                                                                         |
|------------|-----------------|-------------------------------------------------------------------------------|
| **Red**    | **Recoloring**  | 부모와 Uncle을 Black으로, 조부모를 Red로 색칠 → 조부모로 재귀 (전파 가능)                            |
| **Black**  | **Restructuring** | 회전(Rotation): 자식,부모,조부모 중 중간 값을 부모 노드로 나머지를 자식으로 변경 + 색상 교환: 부모-Black, 자식-Red |

### 🧩 Recoloring 예시 (Uncle이 Red인 경우)

```
초기 상태
        50(B)
       /     \
    30(R)   70(R)
```
1. 25(R) 삽입시, Double Red 발생
```
        50(B)
       /     \
    30(R)   70(R)
    /
 25(R)
```
2. Uncle이 70(R)이므로 Recoloring 발생
3. 재귀적으로 부모, 조부모 색상 변경
```
        50(R)
       /     \
    30(B)   70(B)
    /
 25(R)
```
4. Root가 Red이니 Black으로 변환
```
        50(B)
       /     \
    30(B)   70(B)
    /
 25(R)
```

### 🧩 Restructuring 예시 (Uncle이 Black인 경우)
* Uncle이 NIL인 경우도 3번 규칙에 의해 Restructuring
```
초기 상태
        50(B)
       /     \
    30(B)   70(B)
    /
 25(R)
```
1. 10(R) 삽입시, Double Red 발생
```
         50(B)
        /     \
     30(B)   70(B)
     /
  25(R)
  /
10(R)
```
2. Uncle이 NIL(B)이므로 Restructuring 발생
3. 30(B), 25(R), 10(R)를 오름차순 정렬 후, 중간 값을 부모로 회전(rotate)
```
        50(B)
       /     \
    25(R)   70(B)
   /    \
10(B) 30(R)

```
4. 새로 부모가 된 노드를 Black, 자식을 Red로 변경
```
        50(B)
       /     \
    25(B)   70(B)
   /    \
10(R) 30(R)
```

## 삭제 Fix-up : Case별 삭제와 Double black 처리

### 1. 삭제 대상 노드(z) 상황별 처리 + Double Black 발생 여부

| 삭제 대상 z의 색 | 자식 수 | 자식 색상 상황  | 실제로 제거/이동되는 노드(x) | Double Black 발생? | 즉시 처리 방법 (Fix-up 없이 끝나는 경우)                     |
|------------------|---------|-----------|-----------------------------|---------------------|-------------------------------------------------------------|
| Red              | 0       | -         | 없음                        | 발생 안 함          | 그냥 삭제                                                   |
| Red              | 1       | (상관없음)    | 자식이 z 자리로 올라옴        | 발생 안 함          | 자식으로 대체 (색상 그대로 유지 → Red는 규칙에 영향 없음)       |
| Red              | 2       | (상관없음)    | 후속자(또는 선행자)로 교체    | 발생 안 함          | 후속자로 교체 후, 교체된 값 색상 그대로 유지 → Red라 문제 없음 |
| Black            | 0       | -         | NIL 자리                    | 발생                | → Double Black Fix-up 시작                                   |
| Black            | 1       | 자식이 Red   | 자식이 z 자리로 올라옴        | 발생 안 함          | 자식으로 대체 + 자식 색을 **Black으로 강제 변경**             |
| Black            | 1       | 자식이 Black | 자식이 z 자리로 올라옴        | 발생                | 자식으로 대체 → 그대로 Double Black Fix-up 시작              |
| Black            | 2       | (상관없음)    | 후속자(또는 선행자)로 교체    | 교체된 값이 Red면 안 남<br>교체된 값이 Black이면 남 | 교체된 값이 Red면 → Black으로 바꾸고 끝<br>교체된 값이 Black면 → Double Black Fix-up |

**핵심 원칙**
- Red 노드가 사라지거나 이동 → Black-Height 영향 없음 → Fix-up 필요 없음
- Black 노드가 사라지거나 이동 → 반드시 Double Black 보정 필요

### 2. Double Black 발생 시 Fix-up (형제 w 기준 4 Case)

| Case | 형제 w 상태 (한 문장)                                  | 처리 키워드 (순서)                                      | 종료 여부          |
|------|-------------------------------------------------------|-------------------------------------------------------|-------------------|
| 1    | 형제 w가 **Red**                                      | w→Black, 부모→Red, 부모 기준 회전 → 새 형제 보고 재분류   | 미종료             |
| 2    | 형제 w가 **Black**, 두 조카 모두 **Black 또는 NIL**    | w→Red, Double Black을 부모로 전파                      | 부모가 Red면 부모→Black 후 종료 |
| 3    | 형제 w가 **Black**, **바깥쪽 조카**가 Red              | w←부모색, 부모→Black, 바깥쪽 조카→Black, 부모 기준 회전    | 즉시 종료          |
| 4    | 형제 w가 **Black**, **안쪽 조카**가 Red                | 안쪽 조카→Black, w→Red, w 기준 반대 회전 → Case 3 실행   | Case 3에서 종료    |

### 회전 방향 암기법
- x가 **왼쪽** 자식 → Case 1/3: **Left-Rotate(부모)**, Case 4: **Right-Rotate(w)**
- x가 **오른쪽** 자식 → Case 1/3: **Right-Rotate(부모)**, Case 4: **Left-Rotate(w)**
