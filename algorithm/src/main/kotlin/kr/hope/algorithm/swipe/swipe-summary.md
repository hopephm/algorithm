# 🧭 스위핑 알고리즘 요약

---

## 📘 개념

스위핑(Sweep Line)은 **좌표축을 따라 이동하며 이벤트(시작·종료)를 순서대로 처리해 상태를 갱신하는 알고리즘**이다.  
즉, **시작점에서 스트림을 추가하고**, **끝점에서 스트림을 제거하며**,  
각 시점마다 원하는 계산(겹침 수, 길이 등)을 수행한다.

---

## ⚙️ 절차

| 단계       | 설명                                          |
|----------|---------------------------------------------|
| ① 이벤트 정의 | `[start_index, +1]`, `[end_index, -1]` 형태로 표현 |
| ② 정렬     | 좌표 오름차순, 같을 때는 `-1`이 `+1`보다 먼저              |
| ③ 스위핑    | 시작점 → 스트림 추가 / 끝점 → 제거                      |
| ④ 계산     | `count` 변화 시 원하는 연산 수행                      |
| ⑤ 시간 복잡도 | O(N logN)                                   |

## 📘 문제 정의

다음과 같은 1차원 선분 3개가 있다.

| 선분 | 구간 |
|------|------|
| A | [1, 4] |
| B | [2, 6] |
| C | [5, 7] |

**문제:**  
1️⃣ 동시에 겹치는 선분의 최대 개수를 구하라.  
2️⃣ 겹침이 발생하는 구간들을 찾아라.

---

## 📊 시각적 표현 (좌표 기준 정렬)

```
좌표:  0 1 2 3 4 5 6 7
--------------------------------
A:      [=====]
B:        [=======]
C:              [===]
--------------------------------
겹침:       ===   ==
           ^^^   ^^
           2~4   5~6
```

## ⚙️ 이벤트 구성

| 좌표 | 이벤트 | 의미 |
|------|---------|------|
| 1 | +A | 선분 A 시작 |
| 2 | +B | 선분 B 시작 |
| 4 | -A | 선분 A 종료 |
| 5 | +C | 선분 C 시작 |
| 6 | -B | 선분 B 종료 |
| 7 | -C | 선분 C 종료 |

---

## 🧩 스위핑 과정 (왼쪽 → 오른쪽)

| 좌표 | 이벤트 | 활성 스트림 | 겹침 개수(count) |
|------|---------|--------------|------------------|
| 1 | +A | {A} | 1 |
| 2 | +B | {A,B} | 2 ✅ |
| 4 | -A | {B} | 1 |
| 5 | +C | {B,C} | 2 ✅ |
| 6 | -B | {C} | 1 |
| 7 | -C | {} | 0 |
