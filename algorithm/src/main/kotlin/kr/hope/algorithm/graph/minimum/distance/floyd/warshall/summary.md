# 🧭 플로이드-워셜(Floyd–Warshall) 알고리즘 요약

---

## 📘 개념

플로이드-워셜(Floyd–Warshall) 알고리즘은  
**모든 정점 쌍 간의 최단 경로를 한 번에 계산하는 동적 프로그래밍 알고리즘**이다.
- 음수 가중치가 존재해도 동작 (단, 음수 사이클이 없어야 함)
- 각 노드를 "경유지"로 순차적으로 고려하며 거리 행렬을 갱신
- 다익스트라가 **하나의 출발점** 기준이라면,  
  플로이드-워셜은 **모든 출발점에 대해 동시에 계산**

핵심 과정:  
1️⃣ 거리 행렬 초기화 (직접 연결되지 않은 노드는 ∞로 설정)  
2️⃣ 각 노드를 중간 경로(k)로 설정하며  
3️⃣ i→j 최단 거리가 `dist[i][j] > dist[i][k] + dist[k][j]`이면 갱신  
4️⃣ 모든 k, i, j에 대해 반복

---

## ⚙️ 절차

| 단계 | 설명 |
|------|------|
| ① 초기화 | dist[i][j] = 간선 가중치 (없으면 ∞, 자기 자신은 0) |
| ② 점화식 | dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) |
| ③ 반복 | 모든 노드 k(중간점)에 대해 i→j 최단 거리 갱신 |
| ④ 결과 | dist[i][j]는 i에서 j까지의 최단 거리 |
| ⑤ 시간 복잡도 | O(V³), V: 노드 수 |

⚠️ 주의사항
- 중간 정점을 의미하는 k에 대한 반복문이 가장 바깥에 있어야 함
  - 그래야 "특정 정점을 지날 때의 최단거리 값"을 유지하며 유효한 최단 경로를 탐색

💁‍♂️ 응용
- 그래프로 연결된 각 정점 간의 관계를 표현하는데 응용 가능함

---

## 🧩 예시

### 📘 문제 정의

다음 그래프의 모든 정점 쌍 간 최단 거리를 구한다.

**그래프 (노드:1~4, 가중치)**

```
(1)
|   \
4     2
|       \
(2)--1--(3)--3--(4)
```

**가중치 표시**
- 1→2 : 4
- 1→3 : 2
- 2→3 : 1
- 3→4 : 3

---

## 📊 시각적 표현 (거리 행렬 갱신)

### 🥇 초기 거리 행렬

```
     1    2    3    4
1  [ 0,   4,   2,   ∞ ]
2  [ 4,   0,   1,   ∞ ]
3  [ 2,   1,   0,   3 ]
4  [ ∞,   ∞,   3,   0 ]
```

---

### ① k=1을 중간 노드로 고려
- 2→3, 3→4 등은 1을 거쳐도 더 짧지 않음 → 변화 없음

---

### ② k=2를 중간 노드로 고려
- 1→3 vs 1→2→3 = 4+1=5 → 기존 2보다 크므로 변화 없음
- 3→1 vs 3→2→1 = 1+4=5 → 기존 2보다 크므로 변화 없음

변화 없음

---

### ③ k=3을 중간 노드로 고려
- 1→4 = min(∞, 1→3→4 = 2+3=5) → **5로 갱신**
- 2→4 = min(∞, 2→3→4 = 1+3=4) → **4로 갱신**

```
     1    2    3    4
1  [ 0,   4,   2,   5 ]
2  [ 4,   0,   1,   4 ]
3  [ 2,   1,   0,   3 ]
4  [ ∞,   ∞,   3,   0 ]
```

---

### ④ k=4를 중간 노드로 고려
- 3→1, 2→1 등은 4를 거쳐도 개선 없음 → 변화 없음

---

### ✅ 최종 거리 행렬

```
     1    2    3    4
1  [ 0,   4,   2,   5 ]
2  [ 4,   0,   1,   4 ]
3  [ 2,   1,   0,   3 ]
4  [ 5,   5,   3,   0 ]
```

---

## 🕕 시간복잡도

- V: 노드 수
- 모든 (i, j) 쌍에 대해 모든 k를 고려
- 연산 횟수 = V × V × V = **O(V³)**
- 공간 복잡도 = **O(V²)** (거리 행렬 저장)
