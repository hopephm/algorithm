# 🧭 프림(Prim) 알고리즘 요약

---

## 📘 개념

프림(Prim) 알고리즘은  
**그래프의 모든 정점을 최소 비용으로 연결하는 최소 스패닝 트리(Minimum Spanning Tree, MST)**를 찾는 알고리즘이다.  
**임의의 한 정점에서 시작하여, 연결된 간선 중 최소 가중치 간선을 반복적으로 선택**하면서 MST를 확장해 나간다.

핵심 개념:  
1️⃣ 임의의 시작 정점 선택  
2️⃣ 현재 트리에서 나갈 수 있는 간선 중 최소 가중치 간선 선택  
3️⃣ 그 간선의 반대편 정점을 MST에 추가  
4️⃣ 모든 정점이 포함될 때까지 반복

---

## ⚙️ 절차

| 단계 | 설명 |
|------|------|
| ① 초기화 | 임의의 정점을 시작 정점으로 설정, 방문 표시 |
| ② 최소 간선 선택 | 트리 내부 정점에서 외부 정점으로 나가는 간선 중 최소 가중치 간선 선택 |
| ③ 정점 추가 | 선택된 간선의 반대편 정점을 트리에 추가 |
| ④ 반복 | 모든 정점이 포함될 때까지 ②~③ 반복 |
| ⑤ 시간 복잡도 | O(E log V) (우선순위 큐 사용 시) 또는 O(V²) (단순 구현 시) |

⚙️ 핵심 구조
- 정점 위주로 간선을 검사하며 최소 스패닝 트리를 정립함
- 그래프 형태에 따라 구현 방법을 잘 선택해야 함.
  - 정점 수가 적고 간선 수가 많은 그래프 (E ⩬ V²): 정점 검사 단순 반복 구현 O(V²)
  - 정점 수가 많고 희소한 그래프 (E ⩬ V): 우선순위 큐 활용 O(E log V) - 사실상 크루스칼을 사용해도 됨.

⚠️ 최적화
- 최소 스패닝 트리 달성 여부를 방문한 정점(V)수, 추가한 간선 수(V-1)로 판단 가능

---

## 🧩 예시

다음 그래프에서 **1번 정점에서 시작하는 최소 스패닝 트리**를 찾는다.

---

**그래프 (노드:1~5, 가중치)**

```
 (1)
 |  \
 2    7
 |      \
(2)--4--(3)
 |       |
 6       5
 |       |
(4)--3--(5)
```

**간선 목록**

| 간선 | 가중치 |
|------|-----|
| 1-2 | 2   |
| 1-3 | 7   |
| 2-3 | 4   |
| 2-4 | 6   |
| 3-5 | 5   |
| 4-5 | 3   |

---

### 🧩 1️⃣ O(V²) 예시

**시간 복잡도**
- 각 정점 방문 시마다 `O(V)`로 최소 가중치 간선을 탐색
- 전체 정점 `V`번 반복  
  → `O(V²)`

**표기법**
- visited: 방문 여부 (O/X)
- minEdge[i]: i번 정점까지의 최소 연결 비용
- parent[i]: i번 정점과 연결된 최소 연결 정점

### 🥇 초기 상태
- visited: [X, X, X, X, X]  
- minEdge: [0, ∞, ∞, ∞, ∞]
- parent: [1, 2, 3, 4, 5]

① 정점 1 선택
```
- visited: [O, X, X, X, X]  
- minEdge: [0, 2, 7, ∞, ∞] → 1과 연결된 2,3 갱신
- parent: [1, 1, 1, 4, 5]
```
```
현재 트리
 (1)
```
```
후보 트리

 |  \

 |      \
(2)     (3)
```

② 정점 2 선택 (minEdge=2)
```
- visited: [O, O, X, X, X]  
- minEdge: [0, 2, 4, 6, ∞] → 2와 연결된 3,4 갱신 (min(4,7)=4)
- parent: [1, 1, 2, 2, 5]
```

## 🧩 2️⃣ O(E log V) 구현 상태 추적 (우선순위 큐)

**시간 복잡도**
- 간선 삽입/삭제: `E log V`
- 정점 방문: `V`  
  → `O(E log V)`


**표기법**
- visited: 방문 여부
- pq: 최소 힙 (Edge{to, weight})
