# 🧭 최소 스패닝 트리(Minimum Spanning Tree, MST) 요약 (수정본)

---

## 📘 개념

**최소 스패닝 트리(MST, Minimum Spanning Tree)**는  
**가중치가 있는 무방향 연결 그래프(Undirected Weighted Graph)**에서  
**모든 정점을 연결하면서, 간선의 가중치 합이 최소가 되는 부분 그래프**를 말한다.

- **스패닝 트리(Spanning Tree)**:  
  모든 정점을 포함하며 **사이클이 없는 연결 그래프**
- **최소 스패닝 트리(MST)**:  
  가능한 스패닝 트리 중 **간선의 총합이 최소**인 그래프

---

### ⚙️ 특징

| 항목 | 설명 |
|------|------|
| 정점 수 | 원래 그래프의 정점 수 V와 동일 |
| 간선 수 | 항상 V - 1 |
| 연결성 | 모든 정점이 반드시 연결되어야 함 |
| 무사이클 | 사이클이 존재하면 스패닝 트리가 아님 |
| 유일성 | 간선 가중치가 모두 다르면 MST는 유일 |
| 최소성 | 간선 가중치 합이 최소인 트리 |

---

### ⚙️ 주요 알고리즘

| 알고리즘 | 방식 | 시간 복잡도 | 특징 |
|-----------|-------|---------------|------|
| **Kruskal (크루스칼)** | 간선을 가중치 오름차순으로 정렬 후, 사이클이 생기지 않게 순차적으로 추가 | O(E log E) | Union-Find(서로소 집합) 사용 |
| **Prim (프림)** | 하나의 정점에서 시작하여, 최소 비용 간선을 선택해 확장 | O(E log V) | 우선순위 큐(Priority Queue) 사용 |
| **Borůvka (보루프카)** | 각 컴포넌트에서 가장 짧은 간선을 병합 | O(E log V) | 병렬 처리에 적합 |

---

### 💡 응용

| 분야 | 설명 |
|------|------|
| 네트워크 설계 | 통신망, 전력망, 도로망을 최소 비용으로 연결 |
| 클러스터링 | 그래프 기반 거리 최소화 군집 |
| 회로 설계 | 최소 전선 길이로 모든 노드 연결 |
| 인프라 구축 | 최소 자원으로 전 구간 연결 |

---

### ⚠️ 주의사항

| 항목 | 설명 |
|------|------|
| 음수 간선 | 사용 가능 (사이클만 없으면 무관) |
| 방향 그래프 | MST는 **무방향 그래프**에서만 정의 |
| 복수 MST | 동일 가중치를 가진 여러 MST 가능 |
| 사이클 검사 | Kruskal에서는 Union-Find로 필수 검사 |

---

### 🕕 시간복잡도

| 알고리즘 | 그래프 표현 | 시간 복잡도 |
|-----------|---------------|--------------|
| Kruskal | 간선 리스트 | O(E log E) |
| Prim | 인접 리스트 + PQ | O(E log V) |
| Prim | 인접 행렬 | O(V²) |

---

✅ **정리:**
- MST는 “모든 정점을 최소 비용으로 연결하면서, 사이클이 없는 트리”를 의미한다.
- 대표적으로 **Kruskal(간선 중심)**, **Prim(정점 중심)** 알고리즘이 활용된다.

---

## 🧩 시각적 예시

```
그래프 (가중치 포함):

     (1)
    /   \
   1     4
  /       \
(2)---2---(3)
|          |
3          5
|          |
(4)---1---(5)
```

---

### ✅ MST 결과 예시

```
     (1)
    /
   1
  /
(2)---2---(3)
|
3
|
(4)---1---(5)
```

**선택된 간선**
- (1–2) : 1
- (2–3) : 2
- (2–4) : 3
- (4–5) : 1

**총 가중치 합 = 1 + 2 + 3 + 1 = 7**
