# 🧭 포드–풀커슨(Ford–Fulkerson) 알고리즘 요약

---

## 📘 개념

포드–풀커슨(Ford–Fulkerson) 알고리즘은  
**잔여 네트워크에서 증가 경로(Augmenting Path)를 반복적으로 찾아 최대 유량(Max-Flow)을 계산하는 알고리즘**이다.

핵심 개념:  
1️⃣ 잔여 네트워크 구성  
2️⃣ 증가 경로 탐색  
3️⃣ 해당 경로의 최소 잔여 용량만큼 유량 증가  
4️⃣ 역방향 간선을 통해 유량을 취소·조정 가능  
5️⃣ 증가 경로가 없으면 종료

---

## ⚙️ 절차

| 단계 | 설명                           |
|------|------------------------------|
| ① 초기화 | 모든 간선의 유량을 0으로 설정            |
| ② 잔여 네트워크 생성 | r(u,v), 경우에 따라 c(u,v)에 직접 갱신 |
| ③ 증가 경로 탐색 | DFS 또는 BFS 사용                |
| ④ Δ 계산 | 경로 최소 잔여 용량 계산               |
| ⑤ 유량 증가 | f(u,v)+=Δ, f(v,u)-=Δ         |
| ⑥ 잔여 네트워크 갱신 | 정/역방향 잔여 용량 최신화              |
| ⑦ 반복 | 더 이상 증가 경로가 없을 때까지 수행        |


⚙️ 핵심 개념

- **잔여 네트워크(Residual Network)**: 현재 유량 대비 “추가로 보낼 수 있는 양”을 표현하는 그래프
    - 정방향 잔여: c(u,v) - f(u,v)
    - 역방향 잔여: f(u,v)

- **증가 경로(Augmenting Path)**: 잔여 용량이 모두 1 이상인 간선들로만 구성된 s→t 경로

- **역방향 간선**: 이미 흘린 유량을 되돌릴 수 있도록 허용

⚠️ 최적화
- 경로 탐색 시, 이전 정점 존재 여부로 방문 여부 체크 (시작 정점은 별도 값으로 초기화 필요)
- 정점이 너무 많은 경우, 인접리스트 구현을 통해 경로 탑색 시간복잡도를 줄일 수 있음.

⚠️ 주의사항
- 동일 유량에 대해 + 처리
- 인접리스트 위주 최적화 시, 역방향 간선 추가

---

## 🧩 예시

다음 네트워크에서 최대 유량을 구한다.
### 🥇 초기 상태

```
    (s)
   /   \
  5     10
 v       v
(a)--15->(b)
 \       /
  10   10
   v   v
    (t)
```
- **역방향 포함**
```
    (s)
   /   \
 5|0   10|0
 /       \
(a)-15|0-(b)
 \       /
10|0   10|0
   \   /
    (t)
```

## 📊 시각적 과정 (증가 경로 탐색)


---

① 첫 번째 증가 경로
- 경로: **s → a → b -> t**  
- Δ = min(5,15,10) = **5**

```
유량:f(s,a)=0, f(a,b)=10, f(b,t)=5
역방향:f(a,s)=5, f(a,b)=5, f(b,t)=5 
```
```
    (s)
   /   \
 0|5   10|0
 /       \
(a)-10|5-(b)
 \       /
10|0   5|5
   \   /
    (t)
```

---

② 두 번째 증가 경로
- 경로: **s → b → a → t**  
- Δ = min(10,5,10) = **5**

```
유량:f(s,b)=5, f(b,a)=0, f(a,t)=5
역방향:f(b,s)=5, f(a,b)=15, f(t,a)=5 
```
```
    (s)
   /   \
 0|5   5|5
 /       \
(a)-15|0-(b)
 \       /
 5|5   5|5
   \   /
    (t)
```

---

③ 세 번째 증가 경로
- 경로: **s → b → t**  
- Δ = min(5, 5) = **5**

```
유량:f(s,b)=0, f(b,t)=0
역방향:f(b,s)=10, f(b,a)=10 
```
```
    (s)
   /   \
 0|5   0|10
 /       \
(a)-15|0-(b)
 \       /
 5|5   0|10
   \   /
    (t)
```
---

종료
- 더 이상 s에서 나갈 수 있는 유량 미존재
- **최대 유량 = 15**
