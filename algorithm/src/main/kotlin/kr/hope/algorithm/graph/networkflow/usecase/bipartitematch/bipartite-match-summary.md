# 🧭 이분 매칭 문제와 네트워크 유량 활용

---

## 📘 개념

**이분 매칭(Bipartite Matching)** 문제는  
**두 개의 집합 A와 B가 있을 때, 집합 A의 원소와 집합 B의 원소를 1:1로 최대한 많이 매칭하는 문제**를 말한다.

- **목표**: 가능한 매칭 수(maximum matching)를 최대화
- **조건**: 한 원소는 한 번만 매칭 가능
- **그래프 표현**:
    - 이분 그래프(Bipartite Graph)로 표현
    - A 집합과 B 집합을 노드로 두고, 연결 가능한 관계를 간선으로 표현

---

## ⚙️ 네트워크 유량을 활용한 접근

이분 매칭 문제는 **최대 유량(Maximum Flow) 문제로 변환**하여 해결할 수 있다.

1️⃣ **소스(Source)와 싱크(Sink) 노드 추가**
- Source → A 집합 노드로 간선 연결 (용량 1)
- B 집합 노드 → Sink로 간선 연결 (용량 1)

2️⃣ **원래 간선에 용량 1 할당**
- A 집합 노드 → B 집합 노드 연결 간선에 용량 1

3️⃣ **역방향 간선 유량 상쇄 개념 활용**
- 현재까지 흘려보낸 유량(a1:b1 매칭)에 대해 역방향 간선이 생성 됨
- 해당 유량(a1:b1 매칭)을 상쇄하고 다른 유량(a1:bn)을 흘려 보낼 수 있는 경우도 계산

---

## ⚠️ 최적화

1️⃣ 모든 유량이 1이라 유량을 표현할 필요가 없음

2️⃣ 유량 경로가 0..1 이라 단순 매칭으로 표현 가능 

3️⃣ 유량 경로가 그룹A 수에 종속되어 크기에 따라 dfs로 코드 단순화 가능 (stackoverflow 제약 완화)
- dfs 표현시, match 상태가 동일한 경우에는 dfs로 탐색한 경로를 재탐색할 필요없음. (dp 최적화)

4️⃣ 역방향 간선 상쇄를 단순 매칭 변경으로 표현할 수 있음

5️⃣ 특정 집합의 매칭 여부가 유량을 의미하므로 Source와 Sink 노드가 불필요
