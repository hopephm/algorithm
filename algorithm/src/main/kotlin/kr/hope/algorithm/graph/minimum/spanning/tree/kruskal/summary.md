# 🧭 크루스칼(Kruskal) 알고리즘 요약

---

## 📘 개념

크루스칼(Kruskal) 알고리즘은  
**그래프의 모든 정점을 최소 비용으로 연결하는 최소 스패닝 트리(Minimum Spanning Tree, MST)**를 찾는 알고리즘이다.  
**간선을 가중치 오름차순으로 정렬한 뒤, 사이클이 생기지 않도록 간선을 하나씩 선택**한다.

핵심 개념:  
1️⃣ 모든 간선을 가중치 기준으로 정렬  
2️⃣ 가중치가 가장 작은 간선부터 선택  
3️⃣ 선택 시 사이클이 생기지 않으면 MST에 포함  
4️⃣ 모든 정점이 연결될 때까지 반복

---

## ⚙️ 절차

| 단계 | 설명 |
|------|------|
| ① 간선 정렬 | 모든 간선을 가중치 오름차순으로 정렬 |
| ② 사이클 검사 | 선택할 간선의 두 정점이 같은 집합(Union-Find 구조)인지 검사 |
| ③ 간선 선택 | 사이클이 생기지 않으면 해당 간선을 MST에 추가 |
| ④ 반복 | 모든 간선이 검사되거나, V-1개의 간선이 선택될 때까지 반복 |
| ⑤ 시간 복잡도 | O(E log E), E: 간선 수 (정렬 비용 우세) |

⚙️ 핵심 구조
- **Union-Find (Disjoint Set Union, DSU)** 를 사용해 사이클 여부를 효율적으로 검사
- 각 정점은 **대표(parent)** 로 연결되어, 두 정점의 대표가 같으면 이미 연결된 상태임

---

⚠️ 최적화
- 최소 스패닝 트리 달성 여부를 Union 횟수로 판단 가능
  - 최소 스패닝 트리는 Edge가 V-1개 이므로, union 횟수가 V-1이면 각 root를 검사/비교하지 않고도 스패닝트리 달성여부 확인 가능

---

## 🧩 예시

다음 그래프에서 최소 스패닝 트리를 찾는다.

**그래프 (노드:1~5, 가중치)**

```
 (1)
 |  \
 2    3
 |      \
(2)--4--(3)
 |       |
 6       5
 |       |
(4)--7--(5)
```

**간선 목록**
| 간선 | 가중치 |
|------|--------|
| 1-2 | 2 |
| 1-3 | 3 |
| 2-3 | 4 |
| 2-4 | 6 |
| 3-5 | 5 |
| 4-5 | 7 |

---

## 📊 시각적 과정 (간선 선택)

### 🥇 초기 상태
```
MST = ∅  
정점 집합 = {1}, {2}, {3}, {4}, {5}
```

① 간선 1-2 (2)
```
사이클 없음 → 선택  
MST = {(1-2)}  
집합: {1,2}, {3}, {4}, {5}
```

② 간선 1-3 (3)
```
사이클 없음 → 선택  
MST = {(1-2), (1-3)}  
집합: {1,2,3}, {4}, {5}
```

③ 간선 3-5 (5)
```
사이클 없음 → 선택  
MST = {(1-2), (1-3), (3-5)}  
집합: {1,2,3,5}, {4}
```

④ 간선 2-4 (6)
```
사이클 없음 → 선택  
MST = {(1-2), (1-3), (3-5), (2-4)}  
집합: {1,2,3,4,5}
```

이제 모든 정점이 연결됨 (간선 수 = V-1 = 4)

---

### 🏁 최종 결과

**최소 스패닝 트리(MST)**
```
 (1)
 |  \
 2    3
 |      \
(2)     (3)
 |       |
 6       5
 |       |
(4)     (5)
```

총 가중치 = 2 + 3 + 5 + 6 = **16**

---

### 🕕 시간복잡도

- 간선 정렬: O(E log E)
- Union-Find 연산: O(E α(V)) (α는 역아커만 함수, 매우 작음)  
  ➡️ 전체: **O(E log E)**
