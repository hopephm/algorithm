# 🧭 네트워크 유량(Network Flow) 요약

---

## 📘 개념

**네트워크 유량(Network Flow)** 은  
**유향 그래프(Directed Graph)** 에서 각 간선에 **용량(capacity)** 이 존재할 때,  
**소스(Source, s)** 에서 **싱크(Sink, t)** 로 보낼 수 있는 **최대 유량(maximum flow)** 을 구하는 문제 및 그 이론을 말한다.

네트워크 유량 모델은 다음 요소로 구성된다:

- **정점 집합 V**
- **유향 간선 집합 E**
- **간선 용량 c(u, v) ≥ 0**
- **소스 s**, **싱크 t**

유량 함수 f(u, v)는 다음 조건을 만족해야 한다:

1. **용량 제약 (Capacity Constraint)**  
   f(u, v) ≤ c(u, v)

2. **유량 보존 (Flow Conservation)**  
   소스와 싱크를 제외한 모든 정점 v에 대해  
   들어오는 유량 = 나가는 유량  
   Σ f(u, v) = Σ f(v, w)

3. **유량의 대칭 (Value of Flow)**  
   f(u, v) = -f(v, u)

## ⚙️ 특징

| 항목 | 설명 |
|------|------|
| 방향성 | 네트워크 유량은 **유향 그래프** 기반 |
| 용량 | 각 간선은 0 이상의 용량(capacity)을 가짐 |
| 보존 | 소스·싱크 제외 모든 노드는 유량이 보존됨 |
| 잔여 네트워크 | 현재 유량에 따라 새롭게 구성되는 그래프 |
| 최대 유량 | s → t 로 보낼 수 있는 유량의 최댓값 |
| 최소 컷 | 최대 유량 = 최소 컷 용량 (Max-Flow Min-Cut 정리) |

---

## ⚙️ 핵심 구성 요소

### **잔여 용량 (Residual Capacity)**
- r(u, v) = c(u, v) – f(u, v)

### **역방향 간선 (Backward Edge)**
- 유량을 되돌리기 위한 간선으로 f(v, u) = -f(u, v) 를 가짐
- 이미 흘린 유량을 되돌릴 수 있도록 허용함으로써,
  알고리즘이 국소 최적(local optimum)에 갇히지 않고 전역 최적(global optimum)인 최대 유량까지 도달하도록 보장
- -f(u,v)를 추가하더라도 용량 제약과 유량 보존이 지켜짐

### **잔여 네트워크 (Residual Network)**
현재 추가 유량을 흘릴 수 있는 모든 경로를 포함한 그래프

---

## ⚙️ 주요 알고리즘

| 알고리즘 | 방식 | 시간 복잡도                        | 특징 |
|----------|-------|-------------------------------|--------|
| **Ford–Fulkerson** | 증가 경로(Augmenting Path)를 반복적으로 찾음 | O(E × \|f*\|) (유량 크기에 따라 비다항) | 개념적 알고리즘 |
| **Edmonds–Karp** | BFS로 최단 증가 경로를 사용 | O(VE²)                        | 구현 간단, 안정적으로 수렴 |
| **Dinic (디닉)** | 레벨 그래프 + Blocking Flow | O(V²E)                        | 실전에서 매우 빠름 |
| **Push–Relabel** | 정점 단위로 밀기(push)/내리기(relabel) | O(V³)                         | 밀집 그래프에서 강함 |
