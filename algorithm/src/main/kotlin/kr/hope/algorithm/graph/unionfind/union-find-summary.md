# 🧭 유니온 파인드(Union-Find) 알고리즘 요약

---

## 📘 개념

유니온 파인드(Union-Find, Disjoint Set Union, DSU)는  
**여러 원소가 서로 어떤 집합에 속하는지를 효율적으로 관리하는 알고리즘**이다.  
즉, **각 원소의 루트(대표)를 찾고(`find`)**,  
**두 집합을 하나로 합치는(`union`)** 과정을 트리 형태로 수행한다.

---

## ⚙️ 절차

| 단계             | 설명                                                       |
|----------------|----------------------------------------------------------|
| ① 초기화          | 각 원소가 자기 자신을 부모로 갖도록 설정                                  |
| ② `find(x)`    | 원소 `x`의 루트를 찾는다 (경로 압축 시 부모를 루트로 갱신)                     |
| ③ `union(x, y)` | 두 원소의 루트를 찾아, 서로 다른 경우 하나의 루트로 병합                        |
| ④ 최적화          | 트리 높이를 줄이기 위해 **union-by-rank**, **path compression** 적용 |
| ⑤ 시간 복잡도       | O(M * α(N)) (거의 상수 시간, α는 역 아커만 함수, M은 union-find 횟수)    |

---

## 🧩 예시

### 📘 문제 정의

다음은 8개의 원소 `{1, 2, 3, 4, 5, 6, 7, 8}`가 있는 집합이다.  
초기 상태에서는 모든 원소가 **서로 다른 집합**에 속한다.

**문제:**  
1️⃣ `union(1,2) union(2,3) union(4,5) union(5,6) union(6,7) union(3,7)`을 수행 후  
2️⃣ `find(7)`을 수행한다

⚠️ 트리 구조 변경 위주로 확인. 

---

## 📊 시각적 표현 (트리 구조 변화)
⚠️ 실제로는 Union by rank와 path compression이 복합 적용

### 🥇 Union by rank

1️⃣ 초기 상태
```
1  2  3  4  5  6  7  8
```

2️⃣ union(1,2)
```
    1
    └─2
```
3️⃣ union(2,3)
```
    1
 ┌──┴──┐
 2     3
```
4️⃣ union(4,5)
```
    4
    └─5
```
5️⃣ union(5,6)
```
    4
 ┌──┴──┐
 5     6
```
6️⃣ union(6,7)
```
    4
 ┌──┬──┐
 5  6  7
```
7️⃣ union(3,7)
```
   1
┌──┬──┐
2  3  4
   ┌──┬──┐
   5  6  7
```

### 최종형태
```
   1        8
┌──┬──┐
2  3  4
   ┌──┬──┐
   5  6  7
```

---
### 🗜️ Path Compression
8️⃣ find(7) 수행 후 (각 find 시, root 노드에 재귀적으로 연결)
```
           1                 8
 ┌───┬───┬───┬───┬───┐
 2   3   4   5   6   7
```
---
### 🕕 시간복잡도

- n: 전체 노드 개수, m: union/find 연산 횟수
- α(n): 역 아커만 함수, 단일 연산(find/union) amortized 비용
- union(a,b) = 두 번의 find + 상수 연산 → O(α(n))
- find(x) = O(α(n))
- 전체 m번 연산 시간 = O(m · α(n))
