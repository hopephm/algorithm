# 🧭 다익스트라(Dijkstra) 알고리즘 요약

---

## 📘 개념

다익스트라(Dijkstra) 알고리즘은  
**가중치가 있는 그래프에서 특정 시작점에서 다른 모든 노드까지의 최단 경로를 찾는 알고리즘**이다.
- **가중치가 음수가 아닌 경우**에만 적용 가능
- **그리디 접근**으로 현재까지 알고 있는 최단 거리를 기준으로 확장

핵심 과정:  
1️⃣ 시작 노드를 선택하고 거리를 0으로 초기화  
2️⃣ 방문하지 않은 노드 중 최단 거리 노드를 선택  
3️⃣ 선택한 노드를 거쳐 다른 노드로 가는 거리 계산 후 최단 거리 갱신  
4️⃣ 모든 노드를 방문할 때까지 반복

---

## ⚙️ 절차

| 단계              | 설명                                                         |
|-----------------|------------------------------------------------------------|
| ① 초기화           | 시작 노드는 거리 0, 나머지는 ∞로 설정                                    |
| ② 최소 거리 선택     | 방문하지 않은 노드 중 해당 노드까지 도달하는 거리가 가장 짧은 노드 선택                  |
| ③ 거리 갱신        | 선택한 노드를 통해 갈 수 있는 노드의 거리 최솟값으로 갱신                          |
| ④ 방문 처리        | 선택한 노드를 방문 처리, 다시 선택되지 않도록 표시                              |
| ⑤ 반복            | 모든 노드를 방문할 때까지 ②~④ 반복                                      |
| ⑥ 시간 복잡도       | O(V²) (인접행렬) 또는 O(E log V) (우선순위 큐 사용 시), V: 노드 수, E: 간선 수 |

⚠️ 최적화
 - priority queue(최소 힙)를 활용해 인접한 노드중 도달 거리가 가장 짧은 정점 선택
 - 불필요한 중복 처리가 되지 않도록 최소 값이 갱신되는 경우(최단거리 후보)에만 priority queue에 삽입
   - 최소 값이 갱신되지 않았다면, 현재 경로는 이미 최단 경로가 아니기 때문에 가지치기
   - 최소 힙을 활용하는 경우, 이미 최단경로 계산 완료 후 큐에 남은 값을 소진하는 케이스

💁‍♂️ 응용
 - 다익스트라를 역으로 생각할 수 있어야 함 (시작정점 - 도착정점)

## 🧩 예시

### 📘 문제 정의

다음과 같은 그래프에서 **1번 노드에서 다른 모든 노드까지의 최단 거리**를 구한다.

**그래프 (노드:1~5, 가중치)**

```
(1)
|    \
2      4
|        \
(2)---1---(3)
|          |
5          3
|          |
(4)---2---(5)
```

**가중치 표시**
- 1→2 : 2
- 1→3 : 4
- 2→3 : 1
- 2→4 : 5
- 3→5 : 3
- 4→5 : 2

## 📊 시각적 표현 (최단 거리 계산 과정)

### 🥇 초기 상태
```
거리:
1:0  2:∞  3:∞  4:∞  5:∞
방문: 모두 X
```

### ① 노드 1 선택 (거리 0)
```
1 → 2 거리 = 2 → 갱신
1 → 3 거리 = 4 → 갱신

거리:
1:0(방문)  2:2  3:4  4:∞  5:∞
```

### ② 노드 2 선택 (거리 2)
```
2 → 3 거리 = 2+1=3 < 기존 4 → 갱신
2 → 4 거리 = 2+5=7 → 갱신

거리:
1:0  2:2(방문)  3:3  4:7  5:∞
```

### ③ 노드 3 선택 (거리 3)
```
3 → 5 거리 = 3+3=6 → 갱신

거리:
1:0  2:2  3:3(방문)  4:7  5:6
```

### ④ 노드 5 선택 (거리 6)
```
5 → 4 거리 = 6+2=8 > 기존 7 → 갱신 안함

거리:
1:0  2:2  3:3  4:7  5:6(방문)
```

### ⑤ 노드 4 선택 (거리 7)
- 인접 노드 모두 방문 → 갱신 없음

최종 거리:
1:0  2:2  3:3  4:7  5:6

---

### 🕕 시간복잡도

- n = 노드 수, m = 간선 수
- 인접행렬: O(n²)
- 우선순위 큐 + 인접리스트: O(m log n)
