# 🧭 Trie(트라이) 자료구조 요약

---

## 📘 개념

Trie(트라이)는  
**문자열의 공통 접두사(prefix)를 트리 형태로 저장하여, 검색과 자동완성을 빠르게 수행하는 자료구조**이다.  
각 노드는 한 문자를 나타내며, 루트 노드는 빈 문자열을 의미한다.  
문자열 삽입·탐색·접두사 검색 모두 문자열 길이에 비례하여 수행된다 (O(L)).

핵심 개념:  
1️⃣ 문자열의 각 문자를 루트부터 순차적으로 탐색  
2️⃣ 자식 노드가 없으면 새로 생성  
3️⃣ 마지막 문자에서 단어의 끝(`endOfWord`) 표시  
4️⃣ 검색 시 문자가 일치하지 않으면 즉시 탐색 종료

---

## ⚙️ 절차

| 단계 | 설명 |
|------|------|
| ① 초기화 | 루트 노드를 생성 (문자 없음) |
| ② 삽입 (Insert) | 문자열의 각 문자를 순서대로 탐색, 자식 노드가 없으면 생성 |
| ③ 단어 탐색 (Search) | 모든 문자를 순회하며 존재 여부 확인, 마지막 노드가 end이면 존재 |
| ④ 접두사 탐색 (StartsWith) | 주어진 접두사의 문자 경로가 모두 존재하는지만 확인 |
| ⑤ 시간 복잡도 | O(L), L: 문자열 길이 |

🪶 특징
- 빠른 문자열 검색: 탐색 복잡도가 문자열 길이에만 의존
- prefix, suffix 활용: 공통 접두사, 접미사 활용

⚠️ 주의사항
- 메모리: 문자셋이 클 경우 자식 노드 수 증가로 메모리 과도 사용
- 삭제 연산: 삭제 시 다른 단어와 노드 공유 관계에 주의
- 문자열이 짧을 경우 오히려 해시 기반 탐색보다 비효율적

💁‍♂️ 응용
- 노드에 isTerminal 이외의 값을 활용 가능
  - 자식 노드(suffix)에 대한 통계 등
- ReversedTrie를 통해 suffix 탐색 활용
- 문자열 이외 활용: 공통 경로에 대한 정보 

---

## 🧩 예시

저장된 단어: `"car"`, `"cat"`, `"dog"`

```
(root)
├─ c ─ a ─ r (end)
│       └─ t (end)
└─ d ─ o ─ g (end)
```

---

## 📊 시각적 과정 (단어 삽입)

### ① "car" 삽입
```
(root)
└─ c ─ a ─ r (end)
```

### ② "cat" 삽입
```
(root)
└─ c ─ a ─ r (end)
        └─ t (end)
```

### ③ "dog" 삽입
```
(root)
├─ c ─ a ─ r (end)
│       └─ t (end)
└─ d ─ o ─ g (end)
```

---

### 🕕 시간복잡도

- 삽입: O(L)
- 탐색: O(L)
- 접두사 탐색: O(L)  
  (여기서 L은 문자열 길이)
